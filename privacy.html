隐私政策

更新日期：2026年9月28日 · 适用于日序 Mac 与 iPhone 客户端及本支持网站

本政策说明开发者 acxg66（以下简称“我们”）如何通过日序处理与你有关的数据。可选功能只有在相应版本提供且你启用或使用时才适用；请结合应用内提示选择是否使用。

1. 你在日序中保存的资料

日序在设备本地保存你输入或导入的日程、任务、阶段计划、工作记录、笔记、记账数据，以及相关附件、图片、录音、转写、设置和个人空间名称。这些资料用于显示、编辑、搜索、统计、回顾及你请求的其他功能。资料可能包含你本人或他人的个人信息，请只导入或处理你有权使用的内容。

2. 可选的数据同步

  • iCloud：启用后，相应资料、附件及同步所需标识和版本信息保存到你 Apple 账户对应的 iCloud 资料空间，由 Apple 提供存储和传输服务。
  • S3、NAS 或自有同步服务：启用后，所选资料和资源传输到你配置的存储位置。服务商或该位置的管理员可能按其权限及政策访问数据和连接日志。选择具有适当访问控制的服务，并保持存储私有。
  • 分功能同步：支持该功能的版本可分别指定任务、笔记、记账、回顾及设置的同步位置；分配信息通过原 iCloud 资料空间协调。个人空间名称随“设置”同步。

断开同步只停止后续同步，不会自动清空本机或云端副本。切换存储位置也不会自动删除旧端资料。iCloud、S3 和你选择的其他服务可能在其运营地区处理数据；具体地点、保留方式和保护措施取决于相关服务。

3. 系统权限

  • 日历和提醒事项：经系统授权后，读取你选择的日历或清单，并按同步设置创建、更新或删除已关联事项。“仅保存在日序”限制新建内容上传，已关联内容仍可能双向更新。
  • 麦克风：用于你主动开始的录音。音频及转写结果保存在本机；启用对应资料同步后，也可能同步到所选存储端。
  • 文件访问：用于你选择的文件导入、导出、附件、模型或同步目录。
  • 通知：用于你启用的任务和日程提醒。

你可以在系统设置中撤销权限。撤销权限不自动删除已经保存或同步的资料，相关功能可能无法继续使用。

4. AI、本地模型与外部内容

本地处理：本地模型及本地语音识别在设备上处理请求；使用本地处理本身不会把输入发送给远程 AI 接口，但生成结果或录音仍可能随你开启的资料同步上传。

远程 API：使用你配置的远程 AI 服务时，日序会向该服务发送完成请求所需的提示词、对话历史，以及相关功能选取的笔记、工作记录、账目、图片等上下文。接收方取决于你填写的服务地址，其保存、训练使用及删除规则由该服务的政策决定。请确认接收方与请求内容后再使用；不希望发送时，可以不使用远程 AI，改用可用的本地功能。

模型下载与外部内容：下载模型会连接应用标明的模型来源或镜像（例如 Hugging Face）；加载远程图片或打开搜索及外部链接，会连接对应网站。对方可能接收到 IP 地址、请求资源和必要的连接信息；搜索网站也会收到你发起的查询。

5. 密钥与订阅

API 密钥和 S3 凭据通过系统钥匙串保存。启用 API 配置的 iCloud 钥匙串同步后，支持的 API 配置及密钥可通过 Apple 钥匙串在设备间同步；API 密钥不写入普通 iCloud/S3 资料包。S3 凭据按设备保存，不随普通资料同步。

在提供 Apple 内购的 App Store 版本中，订阅及优惠码由 Apple 处理。应用使用 Apple 提供的商品、交易和订阅状态验证会员资格，例如商品标识、有效状态和撤销信息。我们不会因此获得你的银行卡号或支付密码。付款、自动续费、退款和购买记录由 Apple 按其政策处理。开发测试版不等同于已购买会员。

6. 支持联系与网站访问

如果你主动联系我们，我们会处理你提供的邮箱、问题描述、版本信息，以及你自愿发送的截图或日志，用于回应和排查问题。请勿发送 API/S3 密钥、密码、完整私人账本或与问题无关的敏感资料。支持资料仅在处理请求及必要的后续核查期间保留；你可以通过下方联系方式提出删除请求，依法必须保留的部分除外。

本支持网站为静态页面，没有主动嵌入广告、访问分析脚本或第三方字体。发布到 GitHub Pages 后，GitHub 会按其政策处理网站访问所需的请求数据，例如 IP 地址；详见 GitHub 隐私声明。点击外部链接后，适用对应网站的隐私政策。

7. 保留、导出与删除

本地资料在你删除或清理之前保留；回收站、历史版本、录音草稿、导出备份和迁移快照可能保留额外副本。你可以使用应用提供的查看、编辑、导出及删除功能管理资料。若要彻底清理，请同时检查回收站、备份、其他设备和所选云存储；不要仅依靠卸载应用或断开同步。

系统日历/提醒事项中的内容及远程 AI 服务保存的数据需要在相应服务中管理。我们无法代替你直接删除私人 iCloud、S3、自有服务或第三方 AI 服务中的内容。会员到期不会自动删除本机资料。删除资料或卸载应用也不会自动取消 Apple 订阅。

8. 安全与未成年人

我们采用本地存储、系统钥匙串、适用的加密传输和同步校验等措施保护资料，但任何存储或传输方式都不能保证绝对安全。请保护设备、Apple 账户和存储凭据，并保留必要备份。未成年人请在监护人指导下使用涉及个人信息、同步或付费的功能。

9. 政策更新与联系

功能或数据处理方式变化时，我们会更新本页日期；重要变化会通过适当方式说明。你可以联系我们咨询个人信息处理、申请更正或删除你向我们提供的支持资料。
